# DeviceScope

DeviceScope — узнать всё о своём телефоне. Приложение для диагностики устройства: собирает подробную информацию об аппаратной части и позволяет проверить состояние ключевых компонентов.

## Возможности

- Общая информация об устройстве (модель, производитель, Android, прошивка)
- Информация об оборудовании: CPU, RAM, аккумулятор, дисплей, сеть, датчики, камера
- Экранные тесты (цвета, тач, пиксели)
- Бенчмарк производительности
- Просмотр и отправка полного отчёта об устройстве

## Сборка

Требования: JDK 17, Android SDK (compileSdk 35).

```bash
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`.
